# GP 算子手册

> 更新日期：2026-09-10  
> 当前生产空间：90 个算子（34 个 CS、56 个 TS）  
> 实现来源：[`core_func/core/functions.py`](../core_func/core/functions.py)、[`core_func/core/ts_functions.py`](../core_func/core/ts_functions.py)  
> 启用清单：[`core_func/constant/params.py`](../core_func/constant/params.py)

本文按 **CS（横截面）** 和 **TS（时序）** 两类介绍当前 GP 算子。代码已经合并 2026-09-09 的外部最新版 `/data/fund_agent/functions.py` 与 `/data/fund_agent/ts_functions.py`，同时保留当前项目特有的行业排名、横截面回归、TTM 和增长算子。

“代码已注册”和“生产已启用”是两种状态：

- 注册层共有 45 个 CS 算子、73 个 TS 算子族；TS 每族生成 1 个动态窗口名称和 6 个固定窗口名称，共 511 个 TS 注册名。
- 生产 `function_set` 没有直接开放全部注册名，而是启用 90 个经过语义、元数和基础执行检查的固定名称。
- 动态窗口和明显重复、名称误导或会在短窗口下全缺失的算子暂不进入生产搜索空间。

## 1. 总体口径

| 项目 | 当前值 |
|---|---:|
| CS 注册数 / 启用数 | 45 / 34 |
| TS 注册族数 / 启用族数 | 73 / 45 |
| TS 注册名数 / 启用名数 | 511 / 56 |
| 生产算子合计 | 90 |
| 单输入算子 | 66 |
| 多输入算子 | 24 |
| 输入、输出形状 | `[季度, 股票]` |
| 生产最大树深 | 4 |

输入总张量为 `X[季度, 特征, 股票]`。表达式叶子选择一个财务特征后，每个算子接收并返回 `[季度, 股票]` 数组。

公共规则：

- `cs_*` 主要沿股票轴计算同一季度的横截面关系；
- `ts_*` 沿季度轴逐股票计算；
- `NaN` 表示缺失。滚动函数通常跳过窗口中的缺失，但受最少有效样本数约束；
- 当前没有统一输出 winsorize，只有 `cs_indneutral` 明确裁剪到 `[-3,3]`；
- `_d` 后缀不总是实际窗口，必须以各表“实际口径”为准。

## 2. CS 横截面算子

当前生产启用 34 个 CS 算子：14 个单输入、20 个双输入。

### 2.1 单输入 CS 算子（14 个）

| 算子 | 当前定义 | 输出与主要风险 |
|---|---|---|
| `cs_rank(x)` | 当期全市场升序排名 | 原始名次 `1..N`，不是百分位；有效股票数变化会改变尺度 |
| `cs_indrank(x)` | 当期申万一级行业内升序百分位排名 | 范围 `(0,1]`；行业码无效时缺失 |
| `cs_indneutral(x)` | 行业内 `(x-mean)/std` | 样本标准差 `ddof=1`，裁剪到 `[-3,3]`；单样本行业缺失 |
| `cs_abs(x)` | `abs(x)` | 丢失原信号方向 |
| `cs_neg(x)` | `-x` | 反转方向 |
| `cs_sign(x)` | 正、零、负映射为 `1/0/-1` | 强离散化，容易产生大量并列值 |
| `cs_sqrt(x)` | `sqrt(abs(x))` | 压缩极值但抹去符号 |
| `cs_power_third(x)` | `sign(x)×abs(x)^(1/3)` | 压缩极值并保留符号 |
| `cs_log(x)` | `log(abs(x)+1)` | 不是 signed log，负号信息被抹去 |
| `cs_inv(x)` | `1/x` | `abs(x)≤0.001` 返回 0，零附近不连续 |
| `cs_signed_square(x)` | `sign(x)×x²` | 保留方向但强烈放大尾部；无穷值转缺失 |
| `cs_demean(x)` | `x-当期全市场均值` | 保留原量纲，容易受横截面极端值影响 |
| `cs_zscore(x)` | `(x-mean)/sample_std` | `ddof=1`；本项目已将常数截面改为缺失，避免外部草案产生全 1 信号 |
| `cs_switch_packet_flexible(x)` | `-abs(x-当期中位数)` | 越接近横截面中位数得分越高；名称不能直观表达语义 |

行业数据由日频 `SW_IND_CODE` 向前填充到每个报告期，再截取申万一级行业码。行业算子只处理行业码大于 0 的股票。

### 2.2 双输入 CS 算子（20 个）

| 算子 | 当前定义 | 输出与主要风险 |
|---|---|---|
| `cs_add(x,y)` | `x+y` | 量纲不一致时大尺度输入占主导 |
| `cs_sub(x,y)` | `x-y` | 适合构造利差或相对变化 |
| `cs_mul(x,y)` | `x×y` | 原始财务量直接相乘容易数值爆炸 |
| `cs_div(x,y)` | `x/y` | `abs(y)≤0.001` 返回 1；保护值具有经济含义偏置 |
| `cs_max(x,y)` | 逐元素最大值 | 非平滑，任一输入缺失时结果缺失 |
| `cs_min(x,y)` | 逐元素最小值 | 非平滑，任一输入缺失时结果缺失 |
| `cs_residual(y,x)` | 每期横截面 OLS `y=α+βx+ε` 的残差 | 参数顺序是先 `y` 后 `x`；至少 2 个共同有效股票 |
| `cs_regressor(y,x)` | 上述横截面 OLS 的斜率 `β` | 同一期向所有有效股票广播相同系数，单独使用没有横截面排序能力 |
| `cs_signmul(x,y)` | `sign((x-cs_mean(x))×y)` | 不是普通乘法，只输出符号 |
| `cs_zscore_diff(x,y)` | `zx-zy` | 两个不同量纲信号先标准化再求差 |
| `cs_rank_diff(x,y)` | `rank(x)-rank(y)` | 使用原始名次，尺度随股票数变化 |
| `cs_zscore_add(x,y)` | `zx+zy` | 标准化后的等权合成 |
| `cs_zscore_min(x,y)` | `min(zx,zy)` | 表达短板效应，缺失传播 |
| `cs_zscore_max(x,y)` | `max(zx,zy)` | 表达优势效应，缺失传播 |
| `cs_zscore_mul(x,y)` | `zx×zy` | 尺度受控的交互项，方向仍需经济解释 |
| `cs_zscore_ratio(x,y)` | `zx/zy-1` | `abs(zy)≤1e-10` 时缺失，零附近不稳定 |
| `cs_imbalance_coef(x,y)` | `(x-y)/(x+y)` | 适合成对科目的不平衡度；分母接近零时缺失 |
| `cs_zscore_imbalance_coef(x,y)` | `(zx-zy)/(zx+zy)` | 先标准化再计算不平衡度 |
| `cs_zscore_harmonic_mean(x,y)` | `zx×zy/(zx+zy)` | 外部实现没有传统调和平均中的系数 2；嵌套使用时需注意尺度 |
| `cs_double_scored(x,y)` | `x` 分 5 组、组内再排 `y`，两次百分位排名等权平均 | 至少 5 个共同样本且组内至少 2 个；计算成本高于普通向量算子 |

### 2.3 已注册但未启用的 CS 算子（11 个）

```text
cs_sin, cs_cos, cs_tan,
cs_power_2, cs_power_3, cs_sigmoid, cs_fold,
cs_ortho, cs_condition_and, cs_condition_or, cs_mask_ifelse
```

未启用原因主要是经济含义弱、极值或奇点风险、与现有算子重复，以及条件算子容易制造大量缺失。`cs_ortho` 与已启用的 `cs_residual` 等价。

## 3. TS 时序算子

当前生产启用 56 个 TS 固定名称，覆盖 45 个算子族，其中 52 个单输入、4 个双输入。

### 3.1 窗口命名规则

| 算子族 | 后缀与实际行为 |
|---|---|
| `delay/delta/growth/last/avg/qoq/yoy/diff*` | `d` 通常直接作为滞后期数 |
| `ttm` | `d` 直接作为求和窗口 |
| `rank/mean/median/zscore/demean/decay_linear` 及多数新增统计 | 通常使用 `d+1` 窗口 |
| `std/autoslope/cov/corr` 及部分 LMS 统计 | 通常使用 `d+2` 窗口 |
| `first_slope/second_slope/roll_resid/SUE` | 直接使用 `d` 作为回归窗口 |

外部最新版注册固定后缀 `1/2/4/6/8/12`，并注册动态窗口 `dynamic_ts_*`。动态窗口配置为 `(1,12)`，但 `randint` 上界不包含 12，实际只能随机到 1–11。当前生产没有启用动态名称。

### 3.2 基础变化与滚动统计（19 个）

| 已启用算子 | 实际口径 | 最少有效值 / 注意事项 |
|---|---|---|
| `ts_ttm_4(x)` | 最近 4 季求和 | 1；窗口不完整时也输出部分和 |
| `ts_growth_1/2/4(x)` | `(x[t]-x[t-d])/abs(x[t-d])` | 当前与滞后值均有效；滞后值为 0 时缺失 |
| `ts_delta_1/2/4(x)` | `x[t]-x[t-d]` | 前 `d` 期自然缺失 |
| `ts_delay_1/2/4(x)` | `x[t-d]` | 前 `d` 期自然缺失 |
| `ts_avg_2(x)` | `(x[t]+x[t-2])/2` | 不是 2 季滚动均值 |
| `ts_mean_4/8(x)` | 5/9 季滚动均值 | 1；允许不完整窗口 |
| `ts_median_4(x)` | 5 季滚动中位数 | 1；允许不完整窗口 |
| `ts_std_4(x)` | 6 季滚动样本标准差 | 2，`ddof=1` |
| `ts_rank_2/4/8(x)` | 3/5/9 季窗口内当前值排名 | 至少 2 个有效值，映射到 `[0,1]` |
| `ts_quantile_q25_4(x)` | 5 季滚动 25% 分位数 | 至少 3 个有效值 |

该表合并书写的名称仍分别计入生产算子。例如 `ts_growth_1/2/4` 表示 3 个独立注册名。

### 3.6 双输入 TS 算子（4 个）

| 算子 | 实际口径 | 最少有效值 / 注意事项 |
|---|---|---|
| `ts_cov_4(x,y)` | 每只股票的 6 季滚动样本协方差 | 最终至少 3 个共同有效值 |
| `ts_corr_4(x,y)` | 每只股票的 6 季滚动相关系数 | 至少 2 个共同有效值；常数序列缺失 |
| `ts_roll_resid_4(y,x)` | 每只股票在 4 季窗口内回归 `y~1+x`，返回当前残差 | 至少 3 个共同有效值，并等待完整 4 季窗口 |
| `ts_signmul_4(x,y)` | `sign(x-5季滚动均值)×y` | `x` 决定 `y` 的方向；滚动均值至少 3 个有效值 |

### 3.7 已注册但未启用的 TS 算子族（28 个）

```text
min, max, product, pct, skew, kurt,
autocorr_lag1, autocorr_lag2, autocorr_lag3, autocorr_lag4, autocorr_lag5,
argmin, argmax, cut_up_q1, cut_down_q1, count_and, count_or,
```

主要未启用原因：

- `last/qoq/diff*` 与 `delay/growth/delta` 重复；`yoy`、`diff1q`、`diff4q` 的名称又没有锁定相应窗口；
- `rolling_ic` 实际计算滞后滚动回归斜率乘当前信号，并不是 IC；
- `second_slope_1/2/4`、`SUE_1/2` 等短窗组合会全缺失；
- 高阶矩、条件截断和计数算子需要更多覆盖率及性能测试；
- 同一族其他固定窗口虽然已经注册，也不会自动进入 `function_set`。

## 4. 生产空间选择原则

此次升级没有把所有 556 个注册名直接加入生产搜索，原因是：

1. 当前只有约 36 个季度样本，长窗口和完整窗口算子很容易触发 90% 覆盖率门槛；
2. 同一算法开放 6 个固定窗口和动态窗口会产生大量同质表达式；
3. `function_set` 越大，`grow` 建树时选中函数节点的概率越高，会系统性生成更密、更复杂的树；
4. 某些外部名称与真实公式不一致，直接启用会降低研究可解释性；
5. 三元条件算子容易制造缺失，且显著扩大树的分支数。

后续新增窗口时，应先检查：实际窗口、最少有效值、首个可输出季度、全样本平均覆盖率、执行耗时，以及是否与现有算子数学等价。

## 5. 表达式示例

```text
cs_zscore_diff(ts_growth_4(营业总收入), ts_growth_4(营业成本))
```

先分别计算收入和成本同比增长，再做横截面标准化差值，表达增长质量的相对强弱。

```text
cs_indrank(ts_first_slope_4(归属于母公司所有者权益合计))
```

先估计归母权益最近 4 季的线性趋势，再做行业内排名。

```text
ts_roll_resid_4(经营活动产生的现金流量净额, 净利润)
```

对每只股票用最近 4 季净利润解释经营现金流，取当前季度残差。它反映个股自身的现金流—利润时序偏离，而不是股票横截面回归。

## 6. 适应度与结果筛选

当前基础适应度仍为有方向的季度横截面 Pearson IC：

```text
base_fitness = mean_t(corr(factor[t,:], forward_return[t,:]))
adjusted_fitness = base_fitness - 0.05 × (1 - LLM_score/10)
```

- 不对因子或收益排名，不做行业/风格残差化，不取 IC 绝对值；
- 平均覆盖率低于 90% 时基础 fitness 返回 `-1`；单季度覆盖率不足 90% 时该季度不参与 IC；
- 结果列 `base_fitness` 是扣罚前 IC，结果列 `IC` 是扣罚后 fitness；
- 代际表要求 `IC>0`，最终结果当前实际要求 `IC>0.02`。
